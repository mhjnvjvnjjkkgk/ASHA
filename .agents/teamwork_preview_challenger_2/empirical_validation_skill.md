# Empirical Validation Skill (Local Dump)
Core principle: "The code looks correct" is NOT validation. Every change must be verified with empirical evidence before being marked complete.
Verification protocol:
1. Identify verification criteria.
2. Execute verification (run commands, capture actual output/evidence).
3. Document evidence (verbatim output).
4. Confirm against criteria.
Forbidden phrases: "This should work", "The code looks correct", etc.
