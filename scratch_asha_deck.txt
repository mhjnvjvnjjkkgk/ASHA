🔄 4-STEP METHODOLOGY & WORKING PROTOTYPE FLOW
• 1. Spoken / Typed Ingestion & Internal Translation: User speaks in English or Bengali. Continuous Web Speech streams transcript; in-memory translation converts Bengali script into canonical English clinical terms with zero cloud latency.
• 2. ESI Triage, Bed Match & Situational Protocols: Maps symptom to target ward (Cardiac/Adult/Pediatric ICU, General Ward) and blood units (PRBC/Platelets), while immediately rendering step-by-step situational first-aid guidance.
• 3. Atomic Token Hold (15 Min TTL): PostgreSQL executes an atomic hold query. Bed count decrements by 1 across the network, generating a 6-digit OTP entrance pass for the patient.
• 4. Vector Telemetry & Cascade Rerouting: GPS loop monitors travel vector. If target hospital initiates Code Blue diversion, system sounds priority audio alarm and cascade reroutes to next closest facility with all details transferred.
